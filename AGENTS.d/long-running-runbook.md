# 长期任务运行守则（扩展）

* **状态心跳频率：** 在实现阶段或其他耗时操作中，至少每两次工具调用或每 5 分钟提供一次心跳更新，并引用心跳模板字段。
* **指令变更检测：** 每次心跳前主动检查是否收到新的用户指令或上下文变化，如有冲突立刻暂停并请求澄清。
* **日志与记录：** 将自检结果、关键决策和异常情况记录在当前会话的运行笔记或任务纪要中，阶段结束后提供摘要。
* **紧急停止流程：** 遇到高风险操作、权限冲突或不确定性时，立即停止自动执行，汇报现状并等待进一步指示。
* **Codex phase 约定：** 中间进展、工具前说明和长任务心跳使用 `commentary`；最终结论、验证结果和交付摘要使用 `final`。恢复或压缩上下文后，先核对最新用户指令，再继续旧计划。
* **恢复策略：** 中断后先回顾最新心跳记录、计划进度、实际工具输出和最新用户指令，确认目标未变化，再继续执行或返回上一阶段重新规划。

## 心跳汇报模板

| 字段 | 示例 |
| --- | --- |
| 模式 | Implement（自动阶段转换自检#3） |
| 当前步骤 | 计划步骤 2/4 — 生成数据库迁移脚本 |
| 风险/阻塞 | 暂无（权限校验通过） |
| 下一步 | 运行集成测试并复核日志 |
| 监听状态 | 未收到新指令（2025-09-26 14:05 UTC-7） |

> 心跳可按需增减字段，但务必覆盖模式、步骤、风险、下一步与监听状态；最终回复只保留完成结果、验证结论、阻塞项和必要后续动作。
