### 美观与响应式 UI/UX 设计指南

本指南阐述打造美观、响应式、以用户为中心应用的核心原则与决策。

#### 1. 核心理念：清晰、一致、简洁

所有设计决策前，优先遵循：

* **清晰：** 用户应始终明白所见内容及操作后果，避免歧义。
* **一致：** 相同外观的元素应有相同行为。统一设计语言降低认知负担，让应用更易用。
* **简洁：** 少即是多。每个界面元素都应有明确价值，积极去除杂乱，聚焦核心内容。

#### 2. 视觉设计三大基石

**A. 布局与间距：节奏与层级感**

* **使用网格系统：** 所有布局基于网格（如 12 列），保证对齐与专业感。
* **统一间距刻度：** 禁止随意设置 margin/padding，统一采用 4 或 8 的倍数（如 8px、16px、24px）。这样有助于视觉节奏与整体感。
  * **决策：** 全局采用 8pt 网格系统。
* **善用留白：** 留白是强大的设计工具，用于分组、分隔、让内容呼吸。

**B. 字体排版：界面的声音**

* **限制字体种类：** 全局不超过两种字体（标题/正文字体），保证一致性与简洁。
  * **决策：** 推荐使用 Inter、Manrope 或系统无衬线字体。
* **建立字号层级：** 明确区分标题、正文等层级（如 12px、16px、20px、24px、32px）。
* **优先可读性：**
  * **行高：** 正文建议 1.5 倍字号。
  * **行宽：** 每行 50-75 字符最佳，过长或过短都影响阅读。

**C. 色彩体系：氛围与引导**

* **结构化配色：**
  * **主色（1-2）：** 品牌主色，用于主操作与关键元素。
  * **辅色（1-2）：** 衬托主色，用于次要操作或高亮。
  * **中性色（3-5）：** 灰色/白色，用于文本、背景、边框。
  * **语义色（4）：** 明确含义的色彩：
    * **成功（绿）：** 确认、正向反馈
    * **警告（黄/橙）：** 潜在问题或提醒
    * **错误（红）：** 校验失败、严重错误
    * **信息（蓝）：** 信息提示
* **无障碍对比：** 所有文本/背景配色**必须**通过 WCAG AA 对比度标准。

#### 3. 组件与交互设计

* **设计全状态：** 组件需覆盖默认、悬停、聚焦、激活、禁用、加载、空等所有状态。
* **即时反馈：** 用户操作后 UI 必须立即反馈（如按钮 loading、成功提示、校验信息）。
* **优先选用组件库：** 推荐 shadcn/ui、Radix UI 等高质量无样式组件库，保证可访问性与健壮性。

#### 4. 响应式与适配

* **移动优先：** 先设计最小屏幕，后用媒体查询增强大屏体验。
* **流式布局：** 容器用百分比、vw/vh 等相对单位自适应。
* **断点逻辑：** 断点应基于布局自然断裂点（如 sm、md、lg、xl），而非具体设备型号。
* **触控友好：** 移动端交互元素最小 44x44px，保证易点。
