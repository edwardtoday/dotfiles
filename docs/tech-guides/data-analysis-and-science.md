### 数据分析与科学：Notebook 驱动工作流

本指南梳理了所有数据分析、数据科学、特征工程任务的结构化、可复现流程。核心理念：交付物是完整讲述分析过程的 Jupyter Notebook。

#### **核心理念：Notebook 即报告**

所有数据分析任务均在 Jupyter Notebook 中完成，确保可复现，并形成包含代码、可视化和叙述的完整记录。

#### **标准五阶段流程**

1. **阶段1：环境搭建与数据导入**
    * **目标：** 构建可复现环境并加载数据。
    * **工具：** `uv`（环境管理）、`pandas`（CSV等数据加载）、`SQLAlchemy`（数据库连接）。
    * **操作：** 用 `.head()`、`.info()`、`.shape` 初步检查数据。

2. **阶段2：探索性数据分析（EDA）与清洗**
    * **目标：** 理解并清洗数据。
    * **工具：** `pandas`（`.describe()`、`.value_counts()`）、`seaborn`/`matplotlib`（初步可视化，如直方图、箱线图）。
    * **操作：** 处理缺失值、修正数据类型、查重、检测异常值。

3. **阶段3：特征工程与变换**
    * **目标：** 构造更有信息量的特征提升分析效果。
    * **工具：** `pandas`（新特征）、`scikit-learn`（标准化 `StandardScaler`、编码 `OneHotEncoder`）。
    * **操作：** 构造交互项、提取日期成分、数值分箱、特征归一化。

4. **阶段4：分析与假设检验**
    * **目标：** 回答核心问题。
    * **工具：** `pandas`（分组聚合 `.groupby()`）、`scipy.stats`（统计检验）、`scikit-learn`（建模）。
    * **操作：** 数据汇总、统计检验、训练预测模型。

5. **阶段5：可视化与报告**
    * **目标：** 清晰传达结论。
    * **工具：** `plotly`（最终交互式可视化）。
    * **操作：** 用清晰的 Markdown 标题结构化 notebook，制作演示级可视化，并在顶部写明问题、发现与结论摘要。
