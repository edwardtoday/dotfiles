### 图形与可视化：Web 端 2D/3D 技术选型

本指南聚焦现代 Web 2D/3D 图形开发的决策框架。

#### **1. 3D 图形**

**目标：** 在浏览器中渲染交互式 3D 场景、模型与动画。

* **首选：Three.js + react-three-fiber**
  * **原因：** 行业事实标准。`react-three-fiber` 让 Three.js 场景声明式、组件化，完美集成 React，灵活性与生态最佳。
* **备选：Babylon.js**
  * **原因：** 一体化 3D 框架，性能优异，内置丰富工具。适合需要"类游戏引擎"特性的项目。

#### **2. 2D 图形与数据可视化**

**目标：** 渲染 2D 图形、图表、动画或小游戏。

* **交互式数据可视化/图表：SVG + D3.js**
  * **原因：** SVG 分辨率无关、可访问、DOM 原生。D3.js 是数据驱动 DOM 变换的最强库，复杂交互图表首选。
* **动态图形/简单游戏：HTML Canvas API**
  * **原因：** 高性能、底层像素绘制，适合大量简单对象。可用 **Konva.js** 增强对象模型交互。
* **高性能 2D 游戏：PixiJS**
  * **原因：** WebGL 加速 2D 渲染，适合数千精灵、粒子、复杂动画等高性能场景。
