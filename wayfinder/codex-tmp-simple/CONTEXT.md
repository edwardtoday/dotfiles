# Codex 临时工作区领域词汇

## Terms

### 会话记录

由 Codex 自身持久化的对话、工具调用和恢复元数据。会话记录不是任务工作区，不能依赖工作区副本代替。

### 规范工作区

代码或长期资产的权威落点。Git 仓库优先使用现有本地仓库、Codex managed worktree 或明确的永久 worktree；它不属于临时工作区。

### 任务检查点

无法从会话记录、规范工作区、远端 Git 或共享缓存重新得到，但继续任务确实需要的一小组状态和证据。检查点必须有明确 owner 和恢复用途。

### 可再生产物

通过已有源码、依赖声明或命令能够重新生成的内容，例如 `target`、本地安装型 `node_modules`、构建输出、coverage 和下载缓存。可再生产物不是恢复证据。

### 临时工作区

为一次任务提供短期文件落点的受管目录。它不是仓库镜像、长期归档、通用缓存或完整编译环境。

### 活性租约

证明某个会话或进程仍在使用临时工作区的短期信号。租约过期只表示可以重新评估，不直接证明内容可删除。

### 恢复引用

指向规范工作区、远端提交、Codex 快照、共享缓存或检查点包的可验证引用。只有引用可用时，相应主体才可回收。

### 回收

释放实际磁盘块。标记完成、移动到隔离区或写入 manifest 都不是物理回收。

### 例外保留

用户明确要求跨默认期限保留的检查点。例外必须说明理由和复核时间，不能成为普通完成状态的替代品。
